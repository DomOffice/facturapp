Sur le serveur :
cd C:\Temp\FacturApp
le dump :

& "C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" `
  -h 127.0.0.1 `
  -U postgres `
  -d facturapp_db `
  -F c `
  -f "C:\Temp\FacturApp\facturapp_prod.dump"

Sur dev :
coller le dump à cd C:\Temp\FacturApp
arrêter FacturApp si npm run dev tourne
Puis ferme les connexions actives à la base :

& "C:\Program Files\PostgreSQL\18\bin\psql.exe" `
  -h 127.0.0.1 `
  -U postgres `
  -d postgres `
  -c "SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname='facturapp_db' AND pid <> pg_backend_pid();"

Ensuite supprime la base DEV :

& "C:\Program Files\PostgreSQL\18\bin\dropdb.exe" `
  -h 127.0.0.1 `
  -U postgres `
  facturapp_db

Puis recrée-la vide :

& "C:\Program Files\PostgreSQL\18\bin\createdb.exe" `
  -h 127.0.0.1 `
  -U postgres `
  facturapp_db

Et restaure le dump PROD :

& "C:\Program Files\PostgreSQL\18\bin\pg_restore.exe" `
  -h 127.0.0.1 `
  -U postgres `
  -d facturapp_db `
  --no-owner `
  --no-privileges `
  "C:\Temp\FacturApp\facturapp_prod.dump"

  relance DEV :

cd C:\Users\Berrada\Documents\facturapp
npm run dev
