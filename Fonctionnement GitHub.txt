Sur ta machine dev

Avant de commencer :

cd C:\Users\...\Documents\facturapp
git pull
npm run dev

Tu développes et tu testes sur :

http://localhost:3000

Quand tu es satisfait :

git status
git add .
git commit -m "Description courte de la modification"
git push

// Nouvelle méthode :

git status
git add .
git commit 
    Ajouter le titre du commit
    appuyer sur i : pour activer l'insertion
    Ajouter les détails du commit
    Echap
    :wq pour valider
git push

Exemple :

git commit -m "Ajoute filtre sur les factures"
Sur le serveur production

Quand tu veux récupérer la nouvelle version :

cd C:\serveur\facturapp
git pull --ff-only origin main
npm install
npm run build
pm2 restart facturapp

Puis vérifier :

pm2 status
pm2 logs facturapp --lines 50
Règle importante

Sur le serveur : ne modifie plus le code à la main.

Le serveur doit seulement faire :

git pull → build → restart

Le développement doit se faire uniquement sur ta machine.

Accès à la BDD :
npx prisma studio

Verifier qu'il n'y a pas d'erreur :
npx tsc --noEmit

Si erreur persiste :
Ctrl + Shift + P -> reload Window
Ctrl + Shift + P -> Restart TS Server

Commit convention :
feat: → nouvelle fonctionnalité
fix: → correction de bug
refactor: → réorganisation du code sans changement fonctionnel
perf: → amélioration des performances
docs: → documentation
style: → mise en forme (sans changement logique)
test: → ajout ou modification des tests
chore: → maintenance (configuration, dépendances, scripts…)
